Global Superstore Sales Analysis

Project Overview

This project explores Global Superstore sales data using Python to understand sales performance, profitability, customer segments, and product trends.

Objectives

- Analyze sales and profit performance.
- Identify top-performing products and categories.
- Compare regional sales performance.
- Explore customer segments and shipping patterns.
- Present useful business insights through data visualization.

Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

Dataset

The dataset contains transactional information related to orders, customers, products, sales, profit, discounts, and shipping.

Dataset file: "Global-Superstore.csv"

Project Workflow

1. Import the dataset.
2. Inspect rows, columns, and data types.
3. Clean and prepare the data.
4. Perform exploratory data analysis (EDA).
5. Analyze sales and profitability.
6. Visualize patterns and trends.
7. Summarize findings and business recommendations.

Project Files

- "Global-Superstore.csv" — dataset
- "Global_Superstore_Sales_Analysis.ipynb" — Python analysis notebook
- "requirements.txt" — project dependencies

How to Run

1. Open the notebook in Google Colab or Jupyter Notebook.
2. Load the dataset from the repository or upload it to Colab.
3. Install any required dependencies.
4. Run the notebook cells in order.
5. Review the generated tables, charts, and findings.

Analysis Areas

- Sales and profit performance
- Product and category comparisons
- Regional sales performance
- Customer segment analysis
- Discount and profitability relationships
- Shipping patterns and monthly sales trends

The notebook explores these areas using Python, Pandas, Matplotlib, and Seaborn. Findings and recommendations should be interpreted from the results generated by running the notebook.

Conclusion

This project demonstrates data cleaning, exploratory data analysis, Python programming, and data visualization to investigate business performance.
