# Global Superstore Sales Analysis

## Project Overview

This project focuses on analyzing the Global Superstore dataset to understand sales performance, profitability, customer behavior, product categories, and regional trends. Python is used to perform data cleaning, exploratory data analysis (EDA), and visualization to identify useful business insights.

## Objectives

- Analyze overall sales and profit performance.
- Identify top-performing product categories and sub-categories.
- Compare sales and profitability across regions and markets.
- Understand customer segment purchasing patterns.
- Explore the relationship between discounts and profit.
- Analyze monthly sales trends and shipping performance.

## Tools and Technologies

- Python – Data analysis and processing
- Pandas – Data cleaning and manipulation
- NumPy – Numerical operations
- Matplotlib – Data visualization
- Seaborn – Statistical visualization
- Jupyter Notebook / Google Colab – Analysis environment

## Dataset

The project uses the Global Superstore dataset, which contains information about orders, sales, profits, products, customers, regions, discounts, and shipping.

Dataset file: "Global-Superstore.csv"

## Project Workflow

1. Import the required Python libraries.
2. Load and inspect the dataset.
3. Clean the data and check data quality.
4. Perform feature engineering.
5. Calculate key performance indicators (KPIs).
6. Conduct exploratory data analysis.
7. Create visualizations to identify trends and patterns.
8. Summarize findings and business recommendations.

## Key Analysis Areas

- Sales and profit analysis
- Category and sub-category performance
- Regional and market performance
- Customer segment analysis
- Discount versus profitability analysis
- Monthly sales trends
- Shipping mode analysis
- Top-performing products

## Project Structure

- "Global-Superstore.csv" – Dataset used for analysis
- "Global_Superstore_Sales_Analysis.ipynb" – Jupyter notebook containing the analysis
- "README.md" – Project documentation
- "requirements.txt" – Required Python libraries

## How to Run the Project

1. Clone or download this repository.
2. Open "Global_Superstore_Sales_Analysis.ipynb" in Google Colab or Jupyter Notebook.
3. Ensure the dataset is accessible from the notebook.
4. Install the required libraries if they are not already installed.
5. Run the notebook cells in sequence to perform the analysis.
