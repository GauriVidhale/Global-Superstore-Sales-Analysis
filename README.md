# Global Superstore Sales Analysis

## Overview
An end-to-end exploratory data analysis of Global Superstore orders using Python. The project explores sales, profit, product categories, sub-categories, customer segments, markets, regions, discounts, and shipping durations.

## Tools
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook / Google Colab

## Files
- `Global_Superstore_Sales_Analysis.ipynb` — data inspection, cleaning, KPIs, EDA, charts, and draft insights.
- `Global-Superstore.csv` — dataset provided for this analysis.
- `requirements.txt` — Python dependencies.
- `Global-Superstore-Cleaned.csv` — generated by running the notebook; include it in a public repository only if redistribution is permitted.

## Run in Google Colab
1. Open https://colab.research.google.com/
2. Select **File → Upload notebook** and upload `Global_Superstore_Sales_Analysis.ipynb`.
3. Upload `Global-Superstore.csv` into the Colab session.
4. Run cells in order.
5. Review the computed outputs and write conclusions based on the results.

## Data cleaning notes
The provided CSV is read using `encoding="latin1"`. Mostly-empty helper columns are removed. Dates and numeric columns are parsed. Exact duplicate rows are removed if present. Missing postal codes are not imputed because they are absent for many international records.
